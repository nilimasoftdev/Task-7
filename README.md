# Laundry Services - Responsive Design

## About the Project

This project is a Laundry Services landing page created using HTML and CSS. It is part of my CSS assignment to practice responsive web design.

The page includes a navbar, a hero section, text content, a laundry image, and buttons. I used CSS media queries to make the layout responsive for desktop, tablet, and mobile screens.

## Files in the Project

- `index.html`
- `style.css`
- `image_5abe01cb-removebg-preview.png`
- `Readme.md`

## Features

- Responsive navbar
- Desktop navigation links
- Mobile hamburger menu
- Responsive hero section
- Adjustable text and image sizes for different screen sizes
- CSS Flexbox and media queries

## Technologies Used

- HTML
- CSS
- Flexbox
- Media Queries

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser to view the webpage.
